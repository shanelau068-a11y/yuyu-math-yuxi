# 语语预习家 · 四年级数学

给语语（约 9 岁）和家长用的暑假 / 新学期预习小站：人教版 2024 四年级上册数学。手机打开就能用。每次大约 10–15 分钟。先看「学什么」，再「看例题」，然后「练一练」。没有账号，进度只存在这台手机的浏览器里。

在线地址：<https://shanelau068-a11y.github.io/yuyu-math-yuxi/>

## 怎么用

- **GitHub Pages**：推送到仓库默认分支后，按 Pages 设置打开上面的地址。
- **本地打开**：用浏览器打开 `index.html`。朗读要点在手机 Chrome 上更稳。若要离线预习，用手机浏览器「添加到主屏幕」（PWA）。
- 点「今日学习」从下一课开始，点「继续上次」回到刚看的那一课。
- 右上角 ↺ 可以轻轻清掉本地进度，再从头玩一次。
- 计算课的「再练一套」会换新数字，不会超出本课范围（没有小数除法、没有超出三位数乘两位数等）。

## 学什么

目录按人教版 2024 四年级上册（2025 秋 / 2026 秋使用）公开课程地图整理，参考教习网目录与电子课本章节，共 9 个单元、43 课：

1. **大数的认识**（9 课）：亿以内读写、比较改写、近似数、十进制、亿以上、算盘与计算器、整理、1 亿有多大
2. **公顷和平方千米**（3 课）
3. **角的度量**（5 课）：线段直线射线、角、度量、分类、画角
4. **三位数乘两位数**（5 课）：笔算、有 0、积的变化、单价数量总价、速度时间路程
5. **平行四边形和梯形**（5 课）：平行垂直、垂线与距离、平行四边形、梯形、默比乌斯带（拓展）
6. **除数是两位数的除法**（7 课）：口算、一位商、四舍五入试商、不接近整十的试商、两位商、商的变化、整理
7. **条形统计图**（2 课）
8. **数学广角——优化**（3 课）：沏茶、烙饼、田忌赛马
9. **总复习**（4 课）：大数 / 乘除 / 图形 / 统计 各一组综合练

每一课都有：孩子能听懂的预习目标、短讲解要点、2–3 道带步骤的例题、6 道即时对错的练习。综合实践和总复习内容更轻，但不是空课。

讲解与练习均为原创，方便预习。请以纸质课本为准。本站不提供教材插图、扫描件或 PDF。

## 技术

静态 HTML / CSS / JS，无构建、无后端。PWA：`manifest.webmanifest` + `sw.js`。交互节奏与家里的语文站「小小预习家」同一家人：首页 → 单元 → 课，今日学习 / 继续上次，学 / 练。数学课把「认字朗读」换成了「学什么 / 看例题 / 练一练」。

口算生成器只在本课范围内出题，参考了年级范围内练习的常见做法，题目和讲解都重新写过。
